# falcon-pqc

Planned Rust implementation of the Falcon post-quantum signature algorithm.

This crate is an initial placeholder. It does not implement key generation,
signing, or verification and should not be used for cryptographic purposes.

For the algorithm specification and reference implementation, see the
[Falcon project](https://falcon-sign.info/).
